5) LOCATOR STRATEGY (AUTOMATION CONTRACT)

5.1 General Rules
- Scope locators under the comparison section whenever possible
- Prefer role-based and section-scoped locators first
- Use text regex with punctuation tolerance where campaign punctuation may vary
- Avoid broad global getByText checks that match multiple elements

5.2 Recommended Locator Structure & Chaining (CRITICAL FOR AGENT)
When generating locators, YOU MUST define them as functions that accept `page` and YOU MUST chain reusable locators to avoid repeating the parent DOM query.

Do NOT repeat `page.locator('my-account-templates-page-header').filter(...)` for every element. Instead, call the parent locator function.

Example of EXACT REQUIRED FORMAT for `locators.js`:

```javascript
const locators = {
  // Parent Section
  comparisonSection: (page) => page.locator("my-account-templates-page-header")
    .filter({ has: page.getByRole("heading", { name: "Score the Right Membership for You", level: 2 }) })
    .first(),

  // Scoped Section Heading
  sectionHeading: (page) => locators.comparisonSection(page)
    .getByRole("heading", { name: "Score the Right Membership for You", level: 2 }),

  // Tile Roots
  scorecardTile: (page) => locators.comparisonSection(page).locator(".tile-body-copy")
    .filter({ hasText: /1 Point For Every \$1 Spent/i }).first(),

  scorecardPlusTile: (page) => locators.comparisonSection(page).locator(".tile-body-copy")
    .filter({ has: page.getByAltText("ScoreCard Plus New Logo") }).first(),

  // Inner Tile Elements (Chain from the tiles!)
  scorecardGuestCta: (page) => locators.scorecardTile(page).getByRole("button", { name: /sign in\s*\/\s*join now/i })
    .or(locators.scorecardTile(page).getByRole("link", { name: /sign in\s*\/\s*join now/i })),

  scorecardPlusGuestCta: (page) => locators.scorecardPlusTile(page).getByRole("button", { name: /^join now$/i })
    .or(locators.scorecardPlusTile(page).getByRole("link", { name: /^join now$/i }))
    .or(locators.scorecardPlusTile(page).getByRole("button", { name: /join scorecard\+\s*now/i })),
    
  viewAccountScorecardTile: (page) => locators.scorecardTile(page).getByRole("button", { name: /view account/i })
    .or(locators.scorecardTile(page).getByRole("link", { name: /view account/i })),
    
  viewAccountScorecardPlusTile: (page) => locators.scorecardPlusTile(page).getByRole("button", { name: /view account/i })
    .or(locators.scorecardPlusTile(page).getByRole("link", { name: /view account/i }))
};
module.exports = locators;
```

5.3 Strict Mode Safety Rules & Positional Selectors
- NEVER use `.first()` or `.last()` to distinguish between identical CTAs on the page. You MUST scope the CTA to its specific parent tile (e.g., `locators.scorecardTile(page).getByRole(...)`).
- If a text locator can match multiple nodes, use:
  - scoped parent locator
  - class or role plus hasText
  - .first() only after narrowing intent
- Do not put assertions (`expect()`) inside the locators file or page objects. Assertions belong ONLY in specs.

8) ASSERTION GUIDELINES

8.1 Prefer Scoped Assertions
Example:
- Assert undefined/null absence on benefits element text, not entire HTML source.

8.2 Allow Controlled Text Tolerance
- Permit punctuation and superscript variations where business meaning is unchanged.

8.3 CTA Assertions
- Assert presence and clickability in tile context
- Avoid global CTA assertions without section scoping

8.4 Timeout Expectations (CRITICAL)
- The Angular frontend takes time to hydrate. You MUST use a 20000ms timeout for all `toBeVisible()` assertions to avoid flaky 5000ms timeouts.
- Example: `expect(locator).toBeVisible({ timeout: 20000 });`

9) KNOWN RISKS AND MITIGATIONS

Risk: Intermittent unavailable/challenge response for automated runs
Mitigation:
- Retry strategy
- Warmup navigation
- Clear diagnostics and screenshots on failure

Risk: Strict mode failures due to broad locators
Mitigation:
- Section-scoped locators
- Narrow role/text/class combinations

Risk: Campaign copy drift
Mitigation:
- Use business-approved regex tolerance
- Separate hard requirements from promotional copy checks
